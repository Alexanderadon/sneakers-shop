# React Shop — SPA интернет-магазин

Одностраничный магазин кроссовок на React 18: каталог, корзина, избранное. Данные хранятся на mock-бэкенде (MockAPI), все операции идут через REST.

## Функциональность

- Каталог товаров с загрузкой по API (axios), скелетоны на время загрузки (react-content-loader)
- Живой поиск по названию с фильтрацией каталога
- Корзина в выдвижной панели: добавление/удаление товара с синхронизацией на бэкенд, подсчёт итоговой суммы и налога 5%
- Избранное — отдельная страница, состояние тоже пишется в API
- Оформление заказа с очисткой корзины
- Роутинг без перезагрузки страницы (react-router-dom v6)
- Общее состояние через React Context + кастомный хук `useCart`

## Стек

React 18, React Router 6, Axios, SCSS, react-content-loader, Create React App. Бэкенд — MockAPI (REST).

## Запуск

```bash
npm install
npm start
```

Приложение поднимется на `http://localhost:3000`.
